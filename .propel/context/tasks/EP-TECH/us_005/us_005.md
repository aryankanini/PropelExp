# User Story - US_005

## Story ID
- **ID**: US_005

## Story Title
- Restrict native runtime to localhost

## Status
- **State**: Draft
- **Superseded By**: N/A
- **Change Request**: N/A

## Description
- As a local user, I want the application exposed only on my workstation, so that case workflows are not reachable from the network.
- **Estimate**: 3 SP (24 hours)

## Acceptance Criteria

### AC-001: Separate loopback processes
- **Given**: Valid runtime configuration
- **When**: Frontend and backend development processes start
- **Then**: Each binds to a distinct configurable loopback port and exposes an independent health check

### AC-002: Exact origin enforcement
- **Given**: The backend is running
- **When**: A browser request uses an origin other than the configured local frontend origin
- **Then**: The backend rejects the origin without returning protected content

## Edge Cases
- A wildcard origin or non-loopback bind address fails startup validation.
