## Story Title
- Bound provider timeouts and retries
## Status
- **State**: WIP
- **Superseded By**: N/A
- **Change Request**: N/A
## Description
- As a reviewer, I want provider calls bounded, so that transient failures cannot consume the session indefinitely or erase reviewed work.
- **Estimate**: 3 SP (24 hours)
## Acceptance Criteria
### AC-001: Transient retry
- **Given**: A provider call fails transiently
- **When**: Retry policy runs
- **Then**: It retries at most twice with bounded backoff and each attempt times out within the configured limit of 120 seconds
### AC-002: Exhausted retries
- **Given**: All permitted attempts fail
- **When**: The operation terminates
- **Then**: Previously reviewed state remains unchanged and a typed exhausted-retry result is returned
## Edge Cases
- A non-transient schema error is not retried.
