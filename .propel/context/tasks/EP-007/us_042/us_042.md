# User Story - US_042

## Story ID
- **ID**: US_042
## Story Title
- Configure, minimize, and encrypt provider requests
## Status
- **State**: WIP
- **Superseded By**: N/A
- **Change Request**: N/A
## Description
- As a privacy owner, I want OCR and LLM adapters explicitly configured and minimum-necessary requests sent over TLS, so that sensitive content disclosure is bounded and adapters can be swapped without code changes.
- **Estimate**: 8 SP (64 hours)
## Acceptance Criteria
### AC-001: OCR adapter configuration
- **Given**: The backend starts with a valid provider configuration
- **When**: The OCR adapter initializes
- **Then**: The adapter endpoint, API key, and timeout are sourced exclusively from environment configuration and no default or hardcoded values are used
- **And**: A missing or invalid OCR configuration blocks startup before any document is processed

### AC-002: Application-owned port
- **Given**: An approved OCR or LLM operation is needed
- **When**: The application invokes it
- **Then**: An application-owned port sends only the required pages, fields, or evidence over TLS
### AC-003: Replaceable adapter
- **Given**: One provider adapter is replaced by another conforming adapter
- **When**: Domain and application tests run
- **Then**: No domain or application code change is required
## Edge Cases
- A request containing unrelated deficiency text fails the minimum-necessary contract test.
