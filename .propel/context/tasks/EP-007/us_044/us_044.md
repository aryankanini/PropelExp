## Description
- As a delivery team, I want provider adapters contract-tested, so that invalid responses and retry exhaustion behave consistently.
- **Estimate**: 5 SP (40 hours)
## Acceptance Criteria
### AC-001: Valid response contracts
- **Given**: Adapter fixtures satisfy extraction or POC closed schemas
- **When**: Contract tests run
- **Then**: The adapter returns typed application results without provider-specific types crossing the port
### AC-002: Invalid and exhausted contracts
- **Given**: A fixture is schema-invalid or exhausts transient retries
- **When**: Contract tests run
- **Then**: The adapter returns the expected typed failure and no partial payload
## Edge Cases
- Unknown provider fields are rejected even when all required fields are present.
