## Story ID
- **ID**: US_041
## Story Title
- Gate provider configuration approval
## Status
- **State**: WIP
- **Superseded By**: N/A
- **Change Request**: N/A
## Description
- As a privacy owner, I want unapproved providers blocked, so that case content reaches only services with accepted safeguards.
- **Estimate**: 3 SP (24 hours)
## Acceptance Criteria
### AC-001: Approved provider
- **Given**: BAA, retention, training-use, and risk terms are marked approved
- **When**: Provider configuration validates
- **Then**: The adapter may become available for invocation
### AC-002: Unapproved provider
- **Given**: Any required approval is absent
- **When**: Startup or invocation validation runs
- **Then**: The provider is blocked before case content is transmitted
## Edge Cases
- Changing an approval flag at restart revokes availability without exposing its secret values.
