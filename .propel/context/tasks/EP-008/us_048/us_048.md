# User Story - US_048

## Story ID
- **ID**: US_048
## Story Title
- Retry only failed operations
## Status
- **State**: WIP
- **Superseded By**: N/A
- **Change Request**: N/A
## Description
- As a reviewer, I want selective recovery, so that extraction or drafting can resume without repeating valid reviewed work.
- **Estimate**: 5 SP (40 hours)
## Acceptance Criteria
### AC-001: Retry transient failure
- **Given**: Input remains valid and extraction, OCR, or generation failed transiently
- **When**: The reviewer requests recovery
- **Then**: Only the failed operation reruns and successful output returns unconfirmed for review
### AC-002: Replacement required
- **Given**: The source document is invalid or unreadable
- **When**: Recovery is requested
- **Then**: Extraction retry is blocked and a replacement-upload action is returned
### AC-003: Retries exhausted
- **Given**: Provider retries are exhausted
- **When**: The job terminates
- **Then**: Confirmed deficiencies and retained POC work remain unchanged and later retry remains available
## Edge Cases
- Repeated retry commands for one active attempt do not create concurrent provider calls.
