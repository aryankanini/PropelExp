# User Story - US_047

## Story ID
- **ID**: US_047
## Story Title
- Preserve truthful failed-stage state
## Status
- **State**: WIP
- **Superseded By**: N/A
- **Change Request**: N/A
## Description
- As a reviewer, I want failed pages and stages explicit, so that incomplete processing is never presented as confirmed.
- **Estimate**: 3 SP (24 hours)
## Acceptance Criteria
### AC-001: Record affected failure
- **Given**: Extraction or OCR fails for a page or stage
- **When**: The job records the failure
- **Then**: The affected page or stage is identified and unconfirmed payload content is excluded from results
### AC-002: Preserve valid state
- **Given**: Other pages or deficiencies were already validated
- **When**: One stage fails
- **Then**: Valid retained work remains available without being relabeled complete
## Edge Cases
- A terminal event cannot report completed when any required stage remains failed.
