# User Story - US_049

## Story ID
- **ID**: US_049
## Story Title
- Correlate redacted diagnostics
## Status
- **State**: WIP
- **Superseded By**: N/A
- **Change Request**: N/A
## Description
- As an operator, I want correlated structured diagnostics without case content, so that failures can be investigated safely.
- **Estimate**: 5 SP (40 hours)
## Acceptance Criteria
### AC-001: Correlation propagation
- **Given**: An API request starts or a processing job is created
- **When**: It emits responses, events, and logs
- **Then**: One correlation identifier links every related record
### AC-002: Structured safe log
- **Given**: An operation writes a diagnostic
- **When**: Captured logs are inspected
- **Then**: Timestamp, level, correlation ID, actor ID, route or stage, duration, result code, and provider name are present
- **And**: Document text, SOD text, POC text, credentials, and provider payloads are absent
## Edge Cases
- A malicious value resembling a log field is treated as data and redacted rather than altering log structure.
