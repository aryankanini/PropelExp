## Status
- **State**: WIP

## Description
- As a reviewer, I want consistent safe errors, so that I understand the failure without seeing provider internals or sensitive content.
- **Estimate**: 5 SP (40 hours)
## Acceptance Criteria
### AC-001: Stable problem envelope
- **Given**: Validation, authorization, provider, cancellation, or internal handling fails
- **When**: The API returns the failure
- **Then**: The envelope contains a stable code, safe message, correlation ID, retryability, and field errors when validation identifies fields
### AC-002: Sensitive detail exclusion
- **Given**: A failure includes a stack trace or provider payload internally
- **When**: The response is serialized
- **Then**: Neither detail appears in the API or job event
## Edge Cases
- An unknown exception maps to a safe internal code while retaining the same correlation ID for diagnostics.
