# User Story - US_019

## Story ID
- **ID**: US_019
## Story Title
- Validate extraction response schemas
## Status
- **State**: WIP
- **Superseded By**: N/A
- **Change Request**: N/A
## Description
- As a reviewer, I want only schema-valid candidates stored, so that missing evidence and uncertainty cannot appear complete.
- **Estimate**: 3 SP (24 hours)
## Acceptance Criteria
### AC-001: Closed schema accepted
- **Given**: A response contains all required provider, deficiency, evidence, confidence, and uncertainty fields with no unknown fields
- **When**: Adapter validation runs
- **Then**: Candidates enter case state as unconfirmed
### AC-002: Invalid schema rejected
- **Given**: A response omits a required field or adds an unknown field
- **When**: Adapter validation runs
- **Then**: No candidate from the response enters case state and the job records a safe typed failure
## Edge Cases
- A confidence value outside the schema range rejects the candidate instead of being clamped.
- A candidate whose text fields contain only normalization artifacts or whitespace is rejected as empty content.
