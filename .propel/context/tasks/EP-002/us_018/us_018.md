## Story ID

## Story Title
- Detect CMS structure and separate complete deficiency records
## Status
- **State**: WIP
- **Superseded By**: N/A
- **Change Request**: N/A
## Description
- As a reviewer, I want the document's CMS-2567 structure detected and every F-tag and complete SOD separated, so that each deficiency can be reviewed independently.
- **Estimate**: 8 SP (64 hours)
## Acceptance Criteria
### AC-001: CMS structure detection
- **Given**: Normalized page text is available
- **When**: CMS structure detection runs
- **Then**: The document is identified as a CMS-2567 based on structural markers and the detected layout pattern is retained
- **And**: If CMS-2567 structure cannot be established, the document is marked unrecognized and extraction does not proceed

### AC-002: Deficiency boundaries
- **Given**: A document contains multiple detected F-tags
- **When**: Structured extraction completes
- **Then**: Each F-tag has one separate record containing its complete SOD and source evidence
### AC-003: Incomplete SOD
- **Given**: A detected deficiency has no complete SOD boundary
- **When**: Validation runs
- **Then**: The record remains unconfirmed and is marked uncertain for review
## Edge Cases
- Repeated F-tag labels with distinct SOD sections remain separate records.
- A document with recognizable CMS-2567 header markers but no detectable F-tags is marked as structure-detected with zero deficiencies rather than unrecognized.
