## Story Title
- Stream resumable extraction progress
## Status
- **State**: WIP
- **Superseded By**: N/A
- **Change Request**: N/A
## Description
- As a reviewer, I want ordered resumable progress, so that I can follow long extraction jobs through reconnects.
- **Estimate**: 5 SP (40 hours)
## Acceptance Criteria
### AC-001: Ordered progress
- **Given**: An extraction job is running
- **When**: SSE events are emitted
- **Then**: Each event has job ID, increasing event ID, stage, percent, timestamp, and terminal status
### AC-002: Resume after disconnect
- **Given**: The stream disconnects after a known event ID
- **When**: The client reconnects with that ID
- **Then**: Later events resume in order without replaying document text
## Edge Cases
- A second active extraction request is rejected while the original stream remains resumable.
