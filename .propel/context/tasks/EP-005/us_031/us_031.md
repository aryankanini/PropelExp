# User Story - US_031

## Story ID
- **ID**: US_031
## Story Title
- Authenticate local role accounts
## Status
- **State**: Removed - Out of Scope for MVP
- **Superseded By**: N/A
- **Change Request**: N/A
## Description
- As a local user, I want secure authentication with server-assigned authority, so that protected actions match my configured role.
- **Estimate**: 5 SP (40 hours)
## Acceptance Criteria
### AC-001: Successful sign-in
- **Given**: Valid configured credentials
- **When**: The user signs in
- **Then**: Argon2id verification succeeds, the opaque session ID rotates, and a host-only HttpOnly SameSite=Strict cookie is issued
### AC-002: Protected mutation
- **Given**: An authenticated session lacks a valid session-bound CSRF token
- **When**: A mutation is requested
- **Then**: The request is denied without changing state
### AC-003: Role denial
- **Given**: A reviewer session
- **When**: Approval is requested
- **Then**: Route and application authorization both deny the operation
## Edge Cases
- Invalid credentials return one non-specific failure without revealing which field differed.
