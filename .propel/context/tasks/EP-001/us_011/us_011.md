## Story Title
- Stream bounded document uploads

## Status
- **State**: WIP
- **Superseded By**: N/A
- **Change Request**: N/A

## Description
- As a compliance reviewer, I want bounded streamed uploads, so that I can safely submit one supported CMS-2567 document.
- **Estimate**: 5 SP (40 hours)

## Acceptance Criteria
### AC-001: Accepted boundary
- **Given**: No upload is active and a supported file is at most 50 MB and 200 pages
- **When**: The reviewer submits it
- **Then**: The system streams it to the session workspace and starts validation
### AC-002: Exceeded boundary
- **Given**: A file exceeds 50 MB or 200 pages
- **When**: It is submitted
- **Then**: The system rejects it before OCR or AI processing and removes partial files

## Edge Cases
- A second concurrent upload is rejected while the first remains unchanged.
