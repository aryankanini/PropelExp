# User Story - US_015

## Story ID
- **ID**: US_015

## Story Title
- End a working session safely

## Status
- **State**: WIP
- **Superseded By**: N/A
- **Change Request**: N/A

## Description
- As an authorized user, I want to confirm session termination, so that active case content is permanently removed only when I intend it.
- **Estimate**: 3 SP (24 hours)

## Acceptance Criteria
### AC-001: Confirm cleanup
- **Given**: An active case and an explicit removal warning
- **When**: The user confirms end session
- **Then**: Memory and workspace cleanup complete before the UI returns to empty intake
### AC-002: Cancel or fail
- **Given**: The end-session dialog is open
- **When**: The user cancels or cleanup fails
- **Then**: The case remains visible and the system does not claim it was cleared

## Edge Cases
- Repeating the cleanup action after failure is idempotent and cannot reuse the workspace prematurely.
