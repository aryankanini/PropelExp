## Story ID

## Story Title
- Validate CMS-2567 documents

## Status
- **State**: WIP
- **Superseded By**: N/A
- **Change Request**: N/A

## Description
- As a compliance reviewer, I want invalid documents rejected clearly, so that extraction starts only from a readable CMS-2567.
- **Estimate**: 3 SP (24 hours)

## Acceptance Criteria
### AC-001: Valid document
- **Given**: A readable supported CMS-2567 is uploaded
- **When**: Structure validation completes
- **Then**: The case is accepted and marked extraction-ready
### AC-002: Invalid document
- **Given**: A document is unreadable or not a CMS-2567
- **When**: Validation completes
- **Then**: The reason and choose-another-file action appear and no extraction result is created

## Edge Cases
- A mixed PDF with readable and unreadable structure is rejected when CMS-2567 identity cannot be established.
