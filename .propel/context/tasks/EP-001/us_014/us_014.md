# User Story - US_014

## Story ID
- **ID**: US_014

## Story Title
- Expire inactive case sessions

## Status
- **State**: WIP
- **Superseded By**: N/A
- **Change Request**: N/A

## Description
- As a privacy owner, I want inactive case sessions cleaned automatically, so that abandoned case data does not remain on disk or in memory.
- **Estimate**: 3 SP (24 hours)

## Acceptance Criteria
### AC-001: Inactivity cleanup
- **Given**: An authenticated case receives no activity for 60 minutes
- **When**: The inactivity deadline passes
- **Then**: Case metadata and temporary files are removed and verification reports zero remaining case files
### AC-002: Graceful shutdown cleanup
- **Given**: Active transient cases exist
- **When**: The backend shuts down gracefully
- **Then**: The same verified cleanup runs for every case

## Edge Cases
- Activity received exactly at the deadline is ordered deterministically so cleanup cannot race with a retained write.
