## Description
- As a compliance reviewer, I want immutable evidence-linked revisions, so that every correction remains auditable in the active case.
- **Estimate**: 5 SP (40 hours)

## Acceptance Criteria
### AC-001: Append revision
- **Given**: An extracted value has identity, evidence, confidence, origin, and revision data
- **When**: A reviewer edits the value
- **Then**: A new revision becomes current while the original value and evidence remain unchanged

## Edge Cases
- An edit based on a stale revision is rejected with the current revision identifier.
