## Story Title
- Clear transient state idempotently

## Status
- **State**: WIP
- **Superseded By**: N/A
- **Change Request**: N/A

## Description
- As a local user, I want case memory and files cleared together, so that session cleanup has a truthful outcome.
- **Estimate**: 5 SP (40 hours)

## Acceptance Criteria
### AC-001: Complete cleanup
- **Given**: A case has memory state and temporary files
- **When**: Lifecycle cleanup runs one or more times
- **Then**: The aggregate and workspace are absent and the completed status reports zero remaining files
### AC-002: Failed cleanup
- **Given**: Either store cannot be cleared
- **When**: Cleanup runs
- **Then**: The operation reports failed without retaining document content in its status

## Edge Cases
- Repeating cleanup after partial deletion converges on the same completed state.
