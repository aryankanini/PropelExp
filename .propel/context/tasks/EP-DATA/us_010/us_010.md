# User Story - US_010

## Story ID
- **ID**: US_010

## Story Title
- Prevent durable case recovery

## Status
- **State**: WIP
- **Superseded By**: N/A
- **Change Request**: N/A

## Description
- As a privacy owner, I want no durable case records or embedded secrets, so that restart begins clean and protected configuration stays external.
- **Estimate**: 3 SP (24 hours)

## Acceptance Criteria
### AC-001: Empty restart
- **Given**: The backend previously processed a case
- **When**: The backend restarts
- **Then**: Zero case records are recoverable from a database, cache, backup, or migration mechanism
### AC-002: External protected configuration
- **Given**: Runtime configuration is loaded
- **When**: Source and API responses are inspected
- **Then**: Credential hashes, session secrets, provider keys, and approval flags are absent

## Edge Cases
- An ignored local environment file may supply secrets but cannot be committed by the configured ignore rules.
