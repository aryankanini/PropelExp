## Description
- As a reviewer, I want uploads isolated in randomized temporary workspaces, so that client filenames cannot control storage paths.
- **Estimate**: 3 SP (24 hours)

## Acceptance Criteria
### AC-001: Safe streamed ownership
- **Given**: A session accepts an upload stream
- **When**: Bytes are written to temporary storage
- **Then**: The workspace path is randomized, independent of the client filename, and owned by that session
- **And**: A failed stream or validation removes every partial file

## Edge Cases
- A filename containing traversal segments is retained only as metadata and never affects the filesystem path.
